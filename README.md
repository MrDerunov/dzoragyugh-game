# Գյուղը կդիմանա՞ / Выживет ли деревня?

Короткая смешная party-game на 60–90 секунд: игрок тапами по появляющимся объектам спасает армянскую деревню от приезда учеников — уничтожает русизмы, собирает гату и на свой страх и риск трогает овец. Партия заканчивается не просто счётом, а «официальной оценкой ущерба». Полный геймдизайн — в [docs/vyzhivet_li_derevnya_game_design.md](docs/vyzhivet_li_derevnya_game_design.md).

## Возможности

- **Три типа объектов**: полезные — собирай, вредные — уничтожай, странные (овцы и компания) — трогай на свой страх и риск.
- **Комбо с армянскими титулами**: `ԼԱՎ Է` → `ԳԵՐԱԶԱՆՑ` → `ԴՈՒ ՀԱՅ ԵՍ`; ошибка сбивает цепочку.
- **7 специальных событий**: ՄԱՄԱ MODE, ՌՈՒՍԵՐԵՆԻ ՆԵՐԽՈՒԺՈՒՄ, вопрос по грамматике, овцы вне контроля, опоздавший, домашка, армянский босс-слово.
- **Финальная карточка** с абсурдным вердиктом — «Деревня выжила. Армянский — частично.» вместо сухого Game Over.
- **Локальный рейтинг** (localStorage) со «смешными статусами» — от «Спаситель деревни» до «Овцы обеспокоены».
- Работает и как обычный сайт, и внутри Telegram Mini App (вне Telegram — DEV MODE).
- **Пасхалки**: овца на стартовом экране, надоедливая преподавательница и другие.

## Быстрый старт

Нужен Node.js >= 20.

```bash
npm install
npm run dev        # dev-сервер: http://localhost:5173
npm run build      # typecheck + сборка в dist/
npm run preview    # просмотр собранного бандла
npm test           # vitest
npm run typecheck  # tsc --noEmit
```

## Структура проекта

```text
src/
├── core/            — игровое ядро: движок, типы, вердикты (чистая логика, без DOM)
│   └── content.ts   — весь текст, объекты, события и шутки
├── services/        — лидерборд (localStorage) и интеграция с Telegram
└── ui/              — экраны и рендер снимков движка
```

## Деплой

Push в ветку `main` — и GitHub Actions автоматически прогонит тесты, соберёт бандл и опубликует его на GitHub Pages: <https://mrderunov.github.io/dzoragyugh-game/>. Токены и секреты не нужны. Подробности — в [docs/DEPLOY.md](docs/DEPLOY.md).

## Стек и принципы

Vite + TypeScript, без фреймворков. Игровая логика полностью на клиенте, партия не зависит от сети. Контент отделён от кода — шутки, объекты и события легко персонализировать под конкретную группу.
