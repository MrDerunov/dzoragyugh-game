# Архитектура

Как устроен проект и как его развивать. Геймдизайн-документ — [vyzhivet_li_derevnya_game_design.md](vyzhivet_li_derevnya_game_design.md), деплой — [DEPLOY.md](DEPLOY.md).

## 1. Обзор

```text
main.ts — точка входа
   │
   ├── ui/          — экраны и рендер (старт / отсчёт / игра / результат)
   │
   ├── core/        — движок: тик-драйвен, без DOM
   │    └── content — весь текст и шутки
   │
   └── services/    — leaderboard, telegram
            │
            ▼
   внешний мир: localStorage, Telegram WebApp
```

Принцип: игровая логика полностью на клиенте, партия не зависит от сети (см. геймдизайн, §47). Backend — когда появится — нужен только для общего рейтинга: до партии (загрузить таблицу и рекорд) и после (сохранить результат).

## 2. Ядро (src/core)

Чистая логика без DOM и внешних таймеров:

- UI продвигает игровое время вызовами `tick(dtMs)`; движок возвращает снимки состояния (`EngineSnapshot`), которые UI рендерит.
- Детерминизм: `start(seed)` фиксирует зерно ГПСЧ (`mulberry32`), поэтому партию можно «проиграть» в тестах с фиксированным seed.
- Контракт ядра описан в `src/core/types.ts`: `GameEngine`, `EngineSnapshot`, `TapResult`, `GameConfig`, `Verdict` и остальные типы.
- Фабрика `createEngine(config?)` и вердикт `getVerdict(stats, random?)`.

## 3. Контент (src/core/content.ts)

Весь текст, объекты, события, реакции и вердикты отделены от логики:

- `OBJECTS` — описания объектов;
- `EVENTS`, `WEIRD_OUTCOMES` — специальные события и исходы странных объектов;
- `SYSTEM_LINES`, `MISS_REACTIONS` — реакции на действия;
- `COMBO_LINES` / `comboLine()` — титулы комбо (`ԼԱՎ Է` → `ԴՈՒ ՀԱՅ ԵՍ`);
- `PHASE_ANNOUNCEMENTS` — объявления фаз.

Персонализация (геймдизайн, §30): добавить объект в `OBJECTS`, шутку в `SYSTEM_LINES`/`MISS_REACTIONS`, событие в `EVENTS`, имена и мемы группы — механика при этом не меняется.

Мини-пример — новый полезный объект (псевдокод):

```ts
// src/core/content.ts
OBJECTS.push({
  id: 'sudjukh',
  kind: 'good',
  label: 'սուջուխ',
  emoji: '🌭',
  score: 15,
  lifespanMs: 2500,
  reactions: ['ՍՈՒՋՈՒԽԸ ՓՐԿՎԱԾ Է', 'Деревня одобряет'],
});
```

Движок начнёт спавнить объект, а UI нарисует его по `emoji` — без изменений в логике.

## 4. Сервисы (src/services)

- **LeaderboardService** (`src/services/types.ts`): интерфейс `get` / `submit` / `clear`. Сейчас — `createLocalLeaderboard` поверх localStorage (ключ `dzoragyugh.leaderboard.v1`, стартовые «соседи», чтобы рейтинг был живым с первой партии). Позже появится API-реализация (Vercel + Neon) — игра и UI не изменятся.
- **Telegram** (`src/services/telegram.ts`): детекция Mini App, подгрузка SDK, haptics (`tgHaptic`), `initData` для будущего backend. **DEV MODE вне Telegram**: `initTelegram()` возвращает `{ available: false }` — игра работает как обычный сайт (геймдизайн, §65).

## 5. UI (src/ui)

- Экраны: старт, отсчёт, игра, результат.
- Игровой цикл на `requestAnimationFrame`; каждый кадр — `tick(dtMs)`, рендер — diff по снимкам движка.
- Баннеры и всплывающие реакции — из `announcements` ядра и `TapResult`.
- Никакой игровой логики в UI: он только рисует снимки и передаёт тапы в ядро.

## 6. Специальные события

| Событие | Как реализовано |
| --- | --- |
| ՄԱՄԱ MODE | переопределение спавна — поле заполняется едой |
| ՌՈՒՍԵՐԵՆԻ ՆԵՐԽՈՒԺՈՒՄ | переопределение спавна — русизмы, быстро уничтожать |
| Вопрос по грамматике | пауза: `pausedUntil` в снимке — игра замирает на пару секунд |
| Овцы вне контроля | переопределение спавна — странные объекты со случайными исходами |
| Опоздавший | движущийся объект (`moving`) — успеть тапнуть |
| Домашка | чек-лист: среди предметов найти тетрадь |
| Армянский босс-слово | босс-объект с `hp` — несколько тапов до победы |

## 7. Тестирование

vitest — прогнать: `npm test`. Покрыто:

- движок: очки, комбо, фазы, события, детерминизм (фиксированный seed);
- контент: валидность объектов и событий;
- вердикты;
- лидерборд (`src/services/leaderboard.test.ts`).

## 8. Путь к продакшен-версии

1. Персонализация контента под группу (геймдизайн, §30).
2. Векторные ассеты — заменить эмодзи-плейсхолдеры; заменяемые слоты ресурсов по §68–71 (`teacher`, `sergey`, мемы).
3. Звук на WebAudio (§17).
4. Telegram Mini App + Vercel + Neon (§40–61).
5. Достижения и пасхалки (§24–25).

## 9. Принципы

Из геймдизайна (§79):

1. Один тап до игры.
2. Без регистрации.
3. Общий рейтинг.
4. Gameplay независим от backend.
5. Не строить инфраструктуру «на будущее».
6. Сначала смешно.
